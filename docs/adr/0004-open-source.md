# ADR 0004: TronicCAD wird freie Software

Stand 09.11.2026. Status: vom Auftraggeber entschieden. Ersetzt [ADR 0003](0003-commercial-decisions.md).

## Entscheidung

- TronicCAD steht unter der **Apache License 2.0**.
- Jede Person kann alle Funktionen frei nutzen. Es gibt keine Editionen, keine Aktivierung, keine Lizenzabfrage und kein Bezahlsystem.
- Editionen, Lizenzdatei, Lizenzdienst und die Paddle-Anbindung sind entfernt. Sie bleiben in der Git-Geschichte erhalten.
- Die Software nennt in der Oberfläche unter „Hilfe > Fremdkomponenten“ die verwendeten Fremdprogramme und Quelltexte mit vollständigen Lizenztexten.
- Sie lässt sich über [Erweiterungen](../EXTENSIONS.md) ergänzen.
- Das Repository wird erst nach ausdrücklicher Rückfrage öffentlich.
- Veröffentlicht wird als Privatperson, nicht als Firma. Rechteinhaber im Projekt ist das Pseudonym „Tronic3D“.

## Folgen

- Die Phase 8 und die Kriterien zu Verkauf und Lizenzverwaltung entfallen.
- Apache-2.0 erlaubt auch geschlossene Weiterentwicklungen durch andere. Das ist so gewählt.
- Die Marke „TronicCAD“ ist von der Lizenz nicht erfasst, siehe [TRADEMARKS.md](../../TRADEMARKS.md).
- Der CRA kann weiterhin eine Rolle spielen, sobald jemand das Produkt kommerziell bereitstellt. Für freie Software ohne kommerzielle Tätigkeit sieht er Ausnahmen vor. Einzuschätzen ist das fachlich, siehe [CRA_ASSESSMENT.md](../CRA_ASSESSMENT.md).
