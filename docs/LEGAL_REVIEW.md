# Prüfliste für die Rechtsberatung

Stand 04.11.2026. **Das ist keine Rechtsberatung und enthält keine Vertragstexte.** Es sammelt, was vor der Veröffentlichung als freie Software extern zu klären ist. Grundlage ist [ADR 0004](adr/0004-open-source.md).

## Beta-Test

- [ ] Auch kostenlose Weitergabe an Testpersonen ist Weitergabe. Vor der ersten Beta klären: kurze Testvereinbarung, Haftung, Umgang mit Rückmeldungen, Datenschutz für Kontaktdaten
- [ ] Lizenz der LZMA-Kompression im Windows-Installer (Common Public License, siehe `assets/third-party/NSIS-COPYING.txt`) und ihre Pflichten

## Freie Software

- [ ] Veröffentlichung als Privatperson unter dem Pseudonym Tronic3D: Ist das so zulässig, und besteht für Website oder Repository eine Impressumspflicht mit Name und Anschrift
- [ ] Persönliche Haftung als Privatperson, ohne den Schutz einer Firma
- [ ] Welche Rechte an KI-gestützt erzeugtem Code bestehen
- [ ] Haftung trotz Ausschluss in der Apache-Lizenz, besonders bei Fertigungsfehlern und gegenüber Verbrauchern
- [ ] Verträglichkeit aller Fremdlizenzen mit Apache-2.0 und der Weitergabe, auch für das Windows-Installationsprogramm

## Datenschutz

- [ ] Datenschutzerklärung und Rollen, falls ein Clouddienst oder eine Website betrieben wird
- [ ] Das Änderungsprotokoll ist unveränderlich und enthält Kundenkennungen und Gerätenamen. Verhältnis zum Recht auf Löschung
- [ ] Das Audit-Protokoll der Teamfunktion, siehe [SELF_HOSTING.md](SELF_HOSTING.md)
